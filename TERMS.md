## 1. Description of Service

Prompter AI is a client-side Chrome Extension and Web Application that assists users in structuring, scoring, and enhancing artificial intelligence prompts directly within supported web platforms (Google Gemini, ChatGPT, Claude, Perplexity, Microsoft Copilot, and Grok).

---

## 2. Privacy & Local Storage Model

- **Bring Your Own Key (BYOK)**: All provider API keys (Google Gemini, OpenAI, Anthropic, Groq, OpenRouter) are stored exclusively in your local browser storage (`chrome.storage.local`).
- **No Remote Servers**: Prompter AI operates entirely serverless. Your prompts, history, analytics, and memory preferences are stored on your local device.
- **Direct API Connection**: Network requests are dispatched directly from your browser background script to the respective official AI provider endpoints.
